# E2E 테스트 시나리오 (정처기 실기 키워드)

`e2e/app.spec.js`와 1:1로 대응하는 시나리오입니다.

## 실행

프로젝트 루트에서:

```bash
npm run test:e2e
```

`playwright.config.js`가 `python3 -m http.server 8765 --bind 127.0.0.1`로 정적 서버를 띄운 뒤 테스트합니다. 이미 8765 포트가 쓰이면 `reuseExistingServer`로 기존 서버를 재사용합니다.

## S1 — 홈 초기 로딩

- `index.html` 접속 시 로딩이 사라지고 홈이 보인다.
- 제목「정처기 실기」와 키워드 문구가 보인다.

## S2 — 순서대로 학습 (카드 뒤집기 → 정답 → 다음 문제)

-「순서대로」로 학습 화면 진입, 카운터 `1 / N`.
- 카드 앞면 클릭 시 뒤집히고 액션 행(오답/패스/정답)이 보인다.
-「정답」클릭 시 카운터가 `2 / N`으로 증가한다.

## S3 — 테마 토글

- 홈에서 테마 버튼 클릭 시 아이콘(🌙/☀️)이 바뀐다.

## S4 — 통계 화면

-「통계 보기」로 통계 화면이 열리고「학습 통계」가 보인다.

## S5 — 학습 중 홈 복귀 → 이어하기

- 순서대로 진입 후 홈으로 나가면「이어하기」가 보이고 진행 정보가 표시된다.

## S6 — 오답 처리 후「오답만」모드 활성화

- 한 문제를「오답」으로 처리한 뒤 홈에서「오답만」버튼이 활성화된다.

## S7 — 카드 앞면 키보드(Enter)

- 학습 화면에서 카드 앞면에 포커스 후 Enter로 뒤집을 수 있다.

## S8 — 랜덤 모드 진입

-「랜덤」클릭 시 학습 화면에「랜덤」모드 라벨이 보인다.
